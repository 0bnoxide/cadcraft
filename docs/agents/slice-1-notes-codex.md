## Scope and decisions

- Base: scaffold PR #2, `d8f9ffb`. Branch: `slice1/codex-levels`; isolated worktree under `.claude/worktrees/codex-levels`. The main checkout and its unrelated `CLAUDE_TEST.txt` were preserved. Claude has a separate worktree on `slice1/claude-rtk`.
- Read-only behaviour references: AutoGIS `level_loop.py`, ADR-0026, `civil3d_points.py`, `export_survey_cad.py`, `cad_layer_map.py`, the CgPoints writer, and their headless tests. No arcpy, geodatabase writes, Autodesk files, assets or native application input.
- Core: bounded CSV readers, HI levelling, equal-per-setup correction, closure QA and headless elevation selection; PNEZD, mapped layer CSV/CgPoints, mapping resolution and CRS checks.
- Commands: `levelloop` and `pointexport` use the scaffold registration. They accept `csv` text or a native `path`, return JSON and never open dialogs. `pointexport` returns files inline on all platforms; a native `output_dir` must be new. Invalid metadata is checked before creating it. Individual writes reuse engine atomic IO; an IO failure can leave an incomplete new package and is reported as such.
- Units pass through. LandXML requires an explicit EPSG CRS, linear unit (`meter`, `foot`, `USSurveyFoot`), export `date` and `time`; chrono validates the calendar metadata. Caller timestamps avoid a native-only clock in the wasm path. Mapping dictionaries travel through command JSON; YAML adapter loading was not reproduced.
- Preserved reference quirks: a perfectly closed zero-misclosure run has `adjusted=false` and cannot promote elevations; the closing benchmark observation remains raw after correction; side shots use the preceding turning-point correction. Distance weighting remains outside this slice.
- ADR-0026 adds safeguards absent from the current Python implementation: report a missing foresight before a replacement backsight or at the end, require the first observation on the benchmark, and refuse elevation promotion when ERROR findings exist. The original calculation and `adjusted` outputs are retained for diagnosis.
